# OIBSIP Web Development Internship
## Task 1 – Calculator Web Application

### 📌 Objective
To build a basic calculator web application capable of performing arithmetic operations using HTML, CSS, and JavaScript.

---

### 🛠 Technologies Used
- HTML – Structure of calculator layout
- CSS – Styling and responsive design
- JavaScript – Arithmetic logic and event handling

---

### 🚀 Features
- Addition, Subtraction, Multiplication, Division
- Real-time calculation
- Interactive button interface
- Clean and responsive UI

---

### 📂 Project Structure
OIBSIP_WebDevelopment_Task1
│── index.html  
│── style.css  
│── script.js  
│── README.md  

---

### ▶ How to Run
1. Download or clone the repository
2. Open `index.html` in any browser
3. Use the calculator interface
